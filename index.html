Profile

I work on logic, formal verification and AI. My main research line is spatial model checking for image analysis, started in 2016 and developed in the VoxLogicA tools, from the underlying theory (spatial logics, bisimilarity, minimisation) to high-performance implementations and applications in medical imaging.

My current focus is AI that remains inspectable by people: hybrid AI with a strong symbolic component, and software developed by AI agents under formally grounded supervision.

Open problems I’m working on

AI agents that produce new results in explainable image segmentation

Can LLM agents produce real research progress in symbolic, explainable medical image segmentation? Progress counts only if it is reproducible and the procedure stays readable by a person; a better score is not enough.

An ongoing experiment supported by the Anthropic AI for Science Program (2026), built on VoxLogicA 2.

A formally verified, high-performance spatial model checker

Can an image-analysis engine that runs unattended for weeks be both fast and correct by construction? Lazy parallel evaluation, caching and GPU kernels are where performance comes from, and also where errors hide.

VoxLogicA 2.1: the core is a formal model with automatically proved properties, and efficient implementations are derived from it.

Secure, local-first collaboration without central servers

How can people share and edit data, including research data, while keeping it encrypted and under their own control? User interface, network protocols, cryptography and performance have to be designed together, because each one constrains the others.

Nearbytes: a friend-to-friend architecture for encrypted, collaborative data spaces (JLAMP 2026).

Software developed by AI agents that can be trusted

How can software written by AI agents be trusted when no person can read all of it? Agents write code faster than it can be reviewed, so trust has to come from specifications, tests and a process that the agents cannot bypass.

NAIMA: an LLM-driven, multi-agent project-management tool that enforces software-engineering checks; it develops itself and VoxLogicA 2.1.
